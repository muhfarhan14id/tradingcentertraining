# Lanavyn Official – Trader
Platform trading forex bergaya MT5. Harga nyata dari Yahoo Finance chart endpoint (tanpa API key) lewat proxy `api/q.js`.
Fitur: Market Watch, chart candlestick (M1–D1, MA, Bollinger, zoom/geser), Buy/Sell market, Limit/Stop, SL/TP, margin 1:100, stop-out 50%, history + win rate/profit factor, kalkulator risiko.
Akun memakai dana virtual (untuk edukasi); tidak ada deposit/withdraw uang nyata.
## Deploy
1. Push folder ini ke GitHub. 2. Vercel → Import Project → Deploy (tanpa build). Lokal: `npx vercel dev`.
